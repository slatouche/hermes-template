# Anti-slop list

A starter list. One line per tell; add the owner's own as they come (date + what they said).

- Purple-to-blue gradients, glowing blobs or "aurora" backgrounds with no reason to exist.
- Everything centred, every section the same width, the same card grid repeated down the page.
- Three feature cards with an icon, a two-word title and a vague sentence.
- Emoji used as icons or bullet points.
- Generic hero copy ("Unlock the power of…", "Seamless", "Elevate your…"). Say what it does.
- Default system fonts paired with one random display font; more than two typefaces.
- Colours or fonts that aren't tokens in `DESIGN.md`; raw hex values in the code.
- Drop shadows and rounded corners on everything, all the same size.
- Low contrast grey text on grey; light text on busy images.
- Placeholder content left in (lorem ipsum, "John Doe", stock-photo people).
- Buttons that all look primary; no clear single main action per screen.
- Decorative animation that delays the content; motion on every element.
- Icons from mixed sets, sizes or stroke weights.
- Spacing that isn't on the scale (13px here, 17px there).
- Only the happy path designed: no empty, loading, error or long-content state.
- Dashboards of big numbers that don't help any decision.
- Dark mode by inversion: pure black backgrounds with pure white text.
- Tables and lists that ignore small screens.
